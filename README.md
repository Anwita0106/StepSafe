# StepSafe — Disaster Rescue Navigation System

## Live Demo

https://step-safe.vercel.app/


---

## Overview

StepSafe is a web-based Disaster Rescue Navigation System designed to assist emergency response teams in identifying the safest and shortest routes during disaster situations.

The system models a city as a graph and applies classical data structures and algorithms such as Graphs, Queues, Stacks, Priority Queues, BFS, DFS, and Dijkstra's Algorithm to optimize rescue operations. It demonstrates how fundamental computer science concepts can be used to solve real-world emergency navigation problems.

---

## Features

* Interactive disaster area visualization
* Graph-based city route representation
* Safe, Blocked, and Caution zone identification
* Victim location management
* Rescue route generation
* Shortest path calculation using Dijkstra's Algorithm
* Breadth-First Search (BFS) traversal
* Depth-First Search (DFS) traversal
* Priority-based rescue planning
* Real-time route statistics
* System activity logs
* Responsive and user-friendly interface

## Data Structures Used

| Data Structure | Purpose                                         |
| -------------- | ----------------------------------------------- |
| Graph          | Represents locations and routes within the city |
| Queue          | Used for Breadth-First Search (BFS) traversal   |
| Stack          | Used for Depth-First Search (DFS) traversal     |
| Priority Queue | Used in Dijkstra's shortest path algorithm      |
| Hash Map       | Stores location status and victim information   |

## How It Works

1. The city is represented as a weighted graph.
2. Locations are marked as Safe, Caution, or Blocked zones.
3. Rescue teams select a starting location.
4. Victim locations are identified and prioritized.
5. Dijkstra's Algorithm computes the optimal rescue route.
6. BFS and DFS assist in route exploration and traversal.
7. The system displays the safest path and rescue statistics.
